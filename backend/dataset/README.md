# Dataset

- `safe_sites.csv`, `vulnerable_sites.csv` - reference lists of public, safe-to-scan targets
  (columns: `url,description,expected_vulnerabilities`) used for demos/testing. See
  [`../docs/SCANNING_SITES_LIST.md`](../docs/SCANNING_SITES_LIST.md) for the full list and
  legal/ethical notes on scanning.
- `scans.csv`, `vulnerabilities.csv` - **not included**. These would be exports of actual scan
  runs (schema below), but the original exports were built from scans run under authorization
  from the target owners that didn't extend to public redistribution of the findings, so they
  aren't shipped in this repo.

## Schema (for regenerating your own)

`scans.csv`: `id,uuid,target_url,status,scan_type,is_baseline,created_at`

`vulnerabilities.csv`: `id,scan_id,name,severity,confidence,url,parameter,description,is_false_positive,ml_confidence,created_at`

Both can be regenerated by running scans against the targets in `safe_sites.csv`/
`vulnerable_sites.csv` (or any target you're authorized to test) through the scanner's own API
and exporting the results.
